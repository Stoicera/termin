# termin

Build and deployment of [Cal.diy](https://github.com/calcom/cal.diy) (MIT) for the appointment booking of the Stoicera Software Group at https://termin.stoicera.com.

This repo contains no application code: the workflow builds the upstream source at a pinned commit, with public signup disabled, into `ghcr.io/stoicera/termin-cal:<commit>`. Upstream license: MIT, Copyright (c) Cal.com, Inc. — see the upstream repository.
